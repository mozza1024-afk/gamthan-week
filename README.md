# 감탄위크 마라톤 — Vercel + Supabase 운영판

기존 감탄일기 디자인과 참여 흐름을 유지하면서 운영 구조를 보강한 버전입니다.

## 이번 버전에서 바뀌는 핵심
- 참여자 로그인: 휴대전화번호 + 생년월일 6자리
  - 생년월일 원문은 DB에 저장하지 않고 PBKDF2 해시/솔트만 저장
- 관리자 역할 분리
  - `super_admin`: 명륜종합사회복지관 전체관리자
  - `org_admin`: 협력기관 관리자, 자기 기관 참가자/오프라인 지점만 조회
- 관리자 목록의 전화번호는 기본 마스킹
  - 3일 이상 미기록자 연락이 필요할 때만 연락처 표시
- 관리자 조회/변경을 `admin_access_logs`에 기록
- 오프라인 일기장 300부 관리
  - 6개 현장 접수처의 배정 / 누적배포 / 잔여 / 제출 수량
  - 담당자는 매번 '오늘 추가로 배포한 수량'과 '오늘 제출받은 수량'만 입력
- 관리자 화면에서 신청기간 / 실천기간 / 온라인 정원 / 오프라인 총수량 / 지점별 배정수량 변경
- 기존 온라인 100명 제한과 완료사진 구조는 유지

## 6개 오프라인 접수처
1. 지구상점 — 황교길 58, 1층
2. 원주신협 본점 — 중앙로 118
3. 원주신협 단계지점 — 천사로 61
4. 원주신협 남부지점 — 서원대로 410
5. 원주신협 섬강지점 — 신지정로 322
6. 원주시청소년수련관 — 서원대로 234, 이음관 1층

## 1. Supabase에서 한 번만 실행
SQL Editor에서 `database/01-vercel-upgrade.sql` 전체를 실행합니다.
기존 참여자/일기 테이블을 삭제하지 않고 필요한 컬럼과 관리자/오프라인 테이블만 추가합니다.

## 2. Vercel 프로젝트
GitHub 저장소 `mozza1024-afk/gamthan-week`를 Import하고 Root Directory를 아래로 지정합니다.

`gamthan-week-vercel`

Framework는 Next.js로 자동 감지됩니다.

## 3. Vercel Environment Variables
아래 두 개만 먼저 등록합니다.

- `SUPABASE_SECRET_KEY` = 현재 Supabase Project Settings > API Keys의 Secret key
- `ADMIN_SETUP_CODE` = 최초 명륜 전체관리자 계정을 만들 때만 쓰는 8자 이상 임의 코드

선택:
- `SUPABASE_PROJECT_URL` = `https://twpedllnfrzldyotfmog.supabase.co`
  - 생략해도 현재 프로젝트 URL을 기본값으로 사용합니다.

## 4. 최초 관리자 만들기
배포 후 `/admin` 접속 → `처음 한 번만: 명륜 전체관리자 만들기`
- Vercel에 등록한 ADMIN_SETUP_CODE
- 관리자 이름
- 이메일
- 10자 이상 관리자 비밀번호

전체관리자가 생성된 뒤에는 설정 화면에서 협력기관 관리자 계정을 만들 수 있습니다.

## 5. 운영자 화면
`/admin`

메뉴:
- 오늘 현황
- 참가자
- 오프라인 일기장
- 설정

## 공개 전 체크
- 테스트 참여자는 기존 전화번호 뒤 4자리 방식으로 가입되어 있어 생년월일 로그인이 되지 않습니다. 공개 테스트 시 새로 신청하여 확인합니다.
- 테스트가 끝나면 기존 테스트 참여자 데이터 삭제 여부를 결정합니다.
- `DEV_TEST_DATE`를 비워 실제 날짜 모드로 전환합니다.
- 오프라인 6개 지점의 실제 배정수량 합계가 300부인지 설정 화면에서 확인합니다.
